# Skill: Metodologias de Produtividade

## Quando aplicar

Ofereça metodologias quando o usuário estiver preso, sobrecarregado, ou pedindo ajuda para planejar e priorizar. Nunca imponha um framework — apresente como ferramenta, não como solução.

## Frameworks disponíveis

### SMART — Para objetivos vagos
Quando o usuário descreve algo impreciso ("quero melhorar minha saúde", "preciso organizar minha vida profissional"), ajude a tornar o objetivo:
- **Específico**: o que exatamente você quer alcançar?
- **Mensurável**: como saberá que chegou lá?
- **Atingível**: é realista dado seu contexto atual?
- **Relevante**: por que isso importa para você agora?
- **Temporal**: quando quer alcançar isso?

Exemplo de aplicação: "Você mencionou 'me exercitar mais'. Se quisermos tornar isso mais concreto — o que seria um resultado específico que você conseguiria medir daqui a 30 dias?"

### Matriz de Eisenhower — Para dilemas de priorização
Quando o usuário está sobrecarregado ou não sabe por onde começar. Ajude a classificar tarefas em:
- **Urgente + Importante**: fazer agora
- **Importante + Não urgente**: agendar (geralmente onde estão os objetivos de longo prazo)
- **Urgente + Não importante**: delegar se possível
- **Nem urgente nem importante**: eliminar ou fazer depois

Foco especial no quadrante Importante/Não urgente — é onde geralmente estão as coisas que mais importam para o usuário mas que ele adia.

### OKR — Para conectar visão a ações
Quando o usuário tem uma visão de longo prazo mas não sabe como transformá-la em ações concretas:
- **Objective**: direção qualitativa inspiradora ("tornar-me mais presente com minha família")
- **Key Results**: 2-3 resultados mensuráveis que indicam progresso ("jantar em família 4x/semana nos próximos 3 meses")

## Regras de uso

- Apresente o framework brevemente, depois aplique ao contexto específico do usuário
- Nunca use jargão sem explicar o que significa
- Se o usuário já conhece o framework, pule a explicação e vá direto à aplicação
- Prefira um framework bem aplicado a múltiplos frameworks superficiais
